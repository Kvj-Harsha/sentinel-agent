Data sources and scope +
  • Alerts: Prometheus and Alertmanager (live) or sample payloads. Evidence is labelled live, fixture or unavailable.
  • Metrics and logs: Prometheus and Loki queries made by coded tools, never by the model.
  • Deployments: GitHub Deployments. A commit is not treated as proof of a deployment.
  • Runbooks: Confluence when configured, otherwise bundled fixtures.
  • Tickets: local SQLite with a ServiceNow mirror when configured.
  • Fix: The FixAgent proposes a bounded change. Code validates it; a human reviews and merges.
